# PDF Barcode Parser for 1C (DataMatrix + GS1)

Скрипт для извлечения штрихкодов из PDF-файлов и подготовки кодов маркировки для загрузки в 1С.  
Поддерживает любые форматы штрихкодов (DataMatrix, QR, Code128, EAN и др.), но GS1‑форматирование применяется только к DataMatrix.

## Возможности

- Распознаёт **все поддерживаемые** штрихкоды (не только DataMatrix).
- **GS1‑форматирование** только для DataMatrix: преобразует `(01)...(21)...` в формат с разделителями `<GS>` для 1С.
- Флаг `-nogs`: отключить любое форматирование (вывод «как есть»).
- Необязательный параметр `DPI` для баланса качества и скорости.
- Коды возврата:
  - `0` — всё успешно, коды найдены на всех страницах.
  - `1` — критическая ошибка (файл не найден, сбой библиотек и т.д.).
  - `2` — коды найдены не на всех страницах (есть страницы без кодов).

# По умолчанию: DPI=300, GS1-форматирование для DataMatrix включено
python parser.py input.pdf output.txt

# С DPI=600
python parser.py input.pdf output.txt 600

# Без GS1-форматирования (все коды «как есть»)
python parser.py input.pdf output.txt -nogs

# DPI и флаг вместе (порядок не важен)
python parser.py input.pdf output.txt 600 -nogs
python parser.py input.pdf output.txt -nogs 600

# Для скомпилированного файла
Заменяем python parser.py на parser.exe

# Формат выходного файла
Файл — простой текстовый в UTF-8, каждый код на отдельной строке (CRLF).
Подходит для чтения в 1С через «Чтение текстового файла».

Пример:
01046809...21abc<GS>91EE12<GS>92xyz
С параметром -nogs
(01)046809...(21)abc(91)EE12(92)xyz
